## 確定事項

### 画面01｜Landing

目的は「自分に関係がありそう」「短時間でできそう」と理解して開始してもらうこと。

表示優先順位:

1. 「教育資産化診断」
2. 問いかけ
3. 12問・約3分
4. 得られる3つの結果
5. CTA
6. 個人情報不要
7. 教育資産化の定義

原文にある主要表示:

- 問いかけ: 「御社の社内知識は、『教育資産』として活用できていますか？」
- 得られる結果: 教育資産化の現在地、現在のボトルネック、次に取り組むべきこと
- CTA: 「診断を始める」
- 補足: 「個人情報の入力は不要です」
- 定義: 「社内資料やノウハウを、社員が理解し、判断や行動に生かせる形に整え、継続的に活用できる状態にすること」

禁止事項:

- ファーストビューにコンテキストAIの製品ロゴを大きく出さない。
- 「無料」「今すぐリード獲得」感の強い表現にしない。
- 教育資産化の説明を長くしない。

### 画面02〜13｜質問

- 全12問。
- 進捗バーと `現在問 / 12` を表示する。
- 軸名（A〜D）は小さく表示してよい。
- 回答は4択のカードとして表示し、カード全体をクリック可能にする。
- 回答後に自動遷移せず、「次へ」で進む。
- 「戻る」で前問へ戻り、回答を変更できる。
- 未回答では「次へ」を有効化しない。
- 最終問では「診断結果を見る」を表示する。
- 1〜4点の点数はユーザーに見せない。
- 回答の良し悪しを色で示さない。

12問すべての正式な質問文・選択肢は `03_DIAGNOSIS_RULES_AND_CONTENT.md` に記載する。

### 画面14｜結果Hero

- 目的は3秒で「自社の現在地」を理解させること。
- 主役は `LEVEL + 名称 + 一言説明`。
- `48点中○点` を主役にしない。点数を出す場合も補足情報に留める。
- Levelは5段階で、名称と結果文は実装仕様に定義されている。

### 画面15｜4軸 + ボトルネック

- 4軸はレーダーチャートではなく横棒グラフで表示する。
- 軸は「知識の体系化」「教材化」「運用・活用」「測定・改善」。
- 各軸は12点満点として表示例が示されている。
- 最大ボトルネックをカードで強調する。
- 最低点が同点の場合、最大ボトルネックを1つ示し、もう1軸にも同程度の改善余地がある旨を補足する。

### 画面16｜処方箋

- 「まず取り組む3つ」を表示する。
- 3項目以上に増やさない。
- 1項目は「見出し + 1〜2文」とする。
- 「改善してください」ではなく「最初にやること」を示す。
- コンテキストAIの機能名を混ぜない。

### 画面17｜推奨コンテンツ

- 見出しは「今の御社におすすめの記事」。
- 基本2本、最大3本。
- 人気記事ではなく診断結果に合う記事を出す。
- 記事タイトルに加え、「なぜ今読むのか」を1行添える。
- 記事クリックをGA4で計測する。

### 画面18｜Next Action

- 結果価値を十分に提供した後に配置する。
- Primary CTAは「自社資料で教育資産化を試す」。
- ここで初めて「コンテキストAI」を明示する。
- 製品は目的ではなく実行手段として提示する。
- Secondary CTAは「教育資産化とは」。

### 結果画面の固定順序

1. Level: 現在地
2. Type: 最大ボトルネック
3. 4軸: 判定根拠
4. 処方箋: 次の3アクション
5. 推奨記事: 理解を深める
6. 1資料デモ: 実際に体験する
7. 教育資産化とは: 概念へ戻る
